# Software Project Management Console Application
*C# Console Application developed by Dylan Kurowski, Ludmila Klimes, Hector Lopez Onofre, Avital Kuperman, and Tucker Johnson*

> [!NOTE]
> Project is currently under development.

## Overview:
This Project Management System is a C# console-based application designed to assist project managers organize project information and monitor development effort. 

The application will allow users to manage project details, team members, project risks, and functional and non-functional requirements. It also provides effort-tracking functionality to record person-hours on individual requirements and development activities.
